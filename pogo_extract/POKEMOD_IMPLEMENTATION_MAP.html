Pokemod Implementation Map

Every module in the decrypted agent bundle, with the il2cpp classes and methods it hooks.

Extracted from Pokemod's own agent bundle. replace swaps the method outright, attach keeps the original and edits arguments or the return value. Hook names are the game's real method names, so they can be resolved directly by name rather than guessed.
