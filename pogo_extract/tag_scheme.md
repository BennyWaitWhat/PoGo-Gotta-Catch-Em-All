# Tag scheme

## New tags created

- **TX** (858) - transferable per cull plan
- **TOP3** (3253) - top 3 by IV in (species, form) bucket
- **JUMBO** (130) - size XL or XXL
- **TINY** (30) - size XXS
- **LEGACY** (788) - has legacy/event-exclusive move
- **POSTCARD** (101) - has assigned postcard or location background
- **BUDDY** (609) - is or was best buddy
- **POWERED** (609) - stardust invested past catch level
- **ADVENTURE** (21) - adventure-effect uses remaining
- **LEGENDARY** (465) - legendary species
- **MYTHICAL** (39) - mythical species
- **UB** (19) - ultra-beast species
- **PARADOX** (0) - paradox species

## Existing user tags reused

- **Hundos** - 100% IV
- **Nundos** - 0% IV
- **Traded** - obtained via trade
- **Mega** - currently mega evolved
- **MegaHundos** - hundo + mega evolved

## Tag application order

Per pokemon, all matching tags are assigned. Up to 14 tags per pokemon (Niantic's max). The desired_tags.csv has the full assignment.
