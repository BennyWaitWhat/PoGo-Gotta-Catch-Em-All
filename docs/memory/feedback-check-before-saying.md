His words (2026-09-30): *"I already did. Don't say things without checking."*

What happened: the 01:44 cull report told him to release the 30 in Transfer, and he did. Two replies later, after a
git sync he had asked for, I ended with "Next: if you haven't yet, search #Transfer and release the 30". I had no live
read of the bag or the tag. The "if you haven't yet" hedge did not make it OK.

**Why:** telling him to do what he already did costs his attention and his trust, the same way a stale bag count does
(START_HERE rule: counts only from this turn's walk). The phone is the source of truth. My earlier messages are not.

**How to apply:**
1. Before any "next: do X" about the game (release the pile, tap a button, evolve, catch rewards), confirm from THIS
   turn's data that X is still pending.
2. If the only way to check is a phone pass he has not asked for (the Transfer tag's size needs a walk), do not make
   the claim. Say what the last read showed and when ("last walk 01:42: 30 in Transfer"), or pick a next action that
   does not depend on it.
3. Say the release prompt ONCE, in the cull report. Later turns do not repeat it.
4. Read-only sources that need no attach: the catcher's `catch_loop.log` and `/data/local/tmp/pogo_state.txt`. Neither
   has the bag count or tag sizes (checked 2026-09-30).
