Read a script's docstring/argv handling in the source to learn its flags; never execute it to see usage.

**Why:** 2026-09-29 21:28, `python full_audit.py --help | head -30` ran a FULL cull (recrawl, audits, tag sync of 47 mons to the phone) because full_audit only checked for known flags and ignored the rest; `head` then broke the pipe after DONE, so the post-tag steps and pages were cut off (pages regenerated by hand after). Harmless that time (gate passed, server confirmed), but it was an unannounced phone pass. full_audit.py now refuses unknown flags (rc 2, "NOTHING was run"); most other scripts (prune_tags, sync_*, verify_tags_live, one-offs) still do not.

**How to apply:** grep `sys.argv`/argparse or read the header docstring instead. Never pipe a phone-touching script into `head`/`tail` (a broken pipe kills it mid-cycle) — redirect to a file and read the file. See [[feedback-tell-me-what-to-expect]], [[feedback-one-phone-pass-not-three]].
