**ROOT-HIDING HEALTH — two silent failures found 2026-08-04 (check these before blaming anything else for an integrity/banking problem):**
- **Shamiko self-disables when Magisk's "Enforce DenyList" is ON.** Shamiko needs the DenyList *configured but NOT enforced*. Magisk settings DB showed `denylist=1`, and Shamiko's own `module.prop` description rewrites itself live to `[❌ Shamiko doesn't work since enforce denylist is enabled]` — so the module reads "enabled" in the Magisk UI while doing **nothing**, and the ~117 denylisted packages (Amex, Wallet, Play, Authenticator…) fall back to Magisk's weaker, more detectable built-in hiding. Diagnose with `magisk --sqlite "SELECT * FROM settings"` and by reading that description string; fix is toggling Enforce DenyList OFF + reboot.
- **PIF config file precedence — `/data/adb/pif.json` is DEAD, do not read it.** The inject-s module reads **`.prop` files only**, and its loader prefers **`/data/adb/pif.prop` when it exists**, else falls back to `/data/adb/modules/playintegrityfix/pif.prop` (confirmed in the module's own webroot JS + `strings` on `zygisk/arm64-v8a.so`).
