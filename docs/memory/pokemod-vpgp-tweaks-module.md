Pokemod's virtual Go Plus is **two agents, not one**, and missing the second one is why the bot looked like it "caught nothing":

1. `vpgp_agent` -> injected into `com.nianticlabs.pokemongo:pgp`, fakes the BLE device and drives `Module::CatchPokemon` / `SearchPokestop`. Cloned as `pogo_clone/agent_vpgp/vpgp.js`.
2. **`VPGPTweaks`** -> a normal module inside the GAME process. Cloned 2026-09-09 as `pogo_clone/agent/M_VPGPTweaks.js` (module 35).

**Why half two matters:** the bot only ever acts on what the game lets it hear. VPGPTweaks computes from the LIVE bag and storage which accessory notifications the game may hand the device and writes them through `PokemonGoPlus.PgpApi.UpdateNotifications(mask)` -- POKEMON only when there is box room AND >=1 Poke Ball AND no refill in progress, POKESTOP whenever the item bag is not full. It is the thing that stops the vGo Plus burning balls into a full bag. It also zeroes `PgpActivityMonitor.pokemonCatchNotificationDelay` / `pokestopCoolDownPeriodMs` (no wait between actions), persists system/catch/spin through `UpdateWearablesNotifications` before `StartSession` opens, paints a banner naming the reason, hides the two Accessory-Devices toggles it takes over, and reconnects 3 s after a drop.

**SEPTEMBER-BUILD ONLY.** It is absent from the May bundle -- May had an unrelated `PgpUtils` (PlayerStats / SendEncounterRequest) that September deleted. Anything reconciled against May alone will miss it. Source anchors in `fresh_20260908/agent_game_20260908.js`: class `le` stamped `a(le,"VPGPTweaks")`, `T.use("Niantic.Holoholo.Pgp.PgpService")` @2,233,160, English card @1,260,660, strings @1,249,425.

**The Frida trap that this module makes concrete:** Pokemod's Dittolib wrapper passes only DECLARED parameters, so their `o[0]` is the first real argument; raw `Interceptor.attach` gives `args[0]` = `this`. Every hook transcribed from their code must shift by one. Here `StartSession`'s device is `args[1]`, not `args[0]`.

Two framework files it required, both new and reusable: `agent/A_Obfuscation.js` (see [[pogo-game-0427-oracle-obfmap]]) and `agent/A_CustomUI.js` (their `CustomUI`: TopBanner, ScreenTracker, runOnMain, RichText, toUnityColor, Zenject/Holo2 service resolution). CustomUI's banner cannot wire a TAP callback -- minting a UnityAction from the JS realm is the documented crash class in [[pogo-clone-crash-classes]] -- so the "(Click me!)" hint is suppressed rather than shown as a lie.
